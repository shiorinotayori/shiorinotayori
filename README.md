## 🚀 GitHub Pagesへの公開方法

### 1. GitHubリポジトリの作成

1. GitHubにログイン
2. 新しいリポジトリを作成（例：`shiorinotayori-website`）
3. Public（公開）を選択

### 2. ファイルのアップロード

以下のファイルをリポジトリにアップロードしてください：

- `index.html` - メインページ
- `style.css` - スタイルシート
- `script.js` - JavaScript
- `tayorin.png` - たよりんの画像（アップロード画像を使用）

### 3. GitHub Pagesの有効化

1. リポジトリの「Settings」タブを開く
2. 左メニューから「Pages」を選択
3. Source で「Deploy from a branch」を選択
4. Branch で「main」（または「master」）を選択し、フォルダは「/ (root)」を選択
5. 「Save」ボタンをクリック

### 4. 公開URLの確認

数分後、以下のようなURLでサイトが公開されます：
```
https://[あなたのユーザー名].github.io/[リポジトリ名]/
```

## 📝 カスタマイズ方法

### 画像の追加

`tayorin.png` という名前で、たよりんの画像をリポジトリのルートに配置してください。

### 内容の編集

`index.html` を編集することで、テキストや構成を変更できます。

### 色の変更

`style.css` の `:root` セクションで色を変更できます：

```css
:root {
    --primary-green: #6B9E78;  /* メインカラー */
    --light-green: #A8D5BA;    /* サブカラー */
    --sky-blue: #87CEEB;       /* アクセントカラー */
    /* ... */
}
```
