# 小説の一節わかるかな

青空文庫の名作から一節を読んで作品名を当てるクイズサイトです。

## 📁 ファイル構成

```
aozora-quiz/
├── index.html              # メインページ
├── style.css              # スタイルシート
├── quiz.js                # クイズロジック
├── questions-data.xlsx    # 問題データ（Excel）
├── questions-data.js      # 問題データ（JSON・自動生成）
├── excel_to_json.py       # Excel→JSON変換スクリプト
└── README.md              # このファイル
```

## 🚀 セットアップ手順

### 1. 問題データを準備

**方法A: Excelファイルを直接編集（推奨）**

1. `questions-data.xlsx` を開く
2. 「問題データ」シートに問題を追加
   - A列: ID（連番）
   - B列: 作品名
   - C列: 著者名
   - D列: 難易度（easy / medium / hard）
   - E列: 本文一節（**文頭から**入力、400-500文字程度）

**サンプルデータが既に5件入っていますので、参考にしてください。**

### 2. JSONファイルを生成

ターミナルで以下のコマンドを実行：

```bash
cd /Users/toukyoushi/Desktop/栞のたより/HP/aozora-quiz
python3 excel_to_json.py
```

実行すると `questions-data.js` が自動生成されます。

**問題データを追加・変更したら、毎回このコマンドを実行してください。**

### 3. 動作確認

`index.html` をブラウザで開いてテスト

## 🎮 使い方

1. 難易度を選択（初級・中級・上級・全問題）
2. 表示された一節から作品名を推測
3. 「もっと読む」ボタンで100文字ずつ続きを表示
4. 3回以上「もっと読む」を押すと著者名のヒントが表示
5. 選択肢から作品名を選択
6. 10問終了後に結果を表示

## 📝 データの追加方法

### Excelファイルに追加

1. `questions-data.xlsx` を開く
2. 最終行の下に新しい行を追加
3. 以下の形式で入力：

```
ID: 連番（6なら6と入力）
作品名: こころ
著者名: 夏目漱石
難易度: easy / medium / hard
本文一節: 文頭から400-500文字程度を入力
```

**重要：本文一節は必ず文頭から入力してください。**
クイズでは最初は100文字だけ表示され、「もっと読む」ボタンで段階的に表示されます。

4. 保存して、`python3 excel_to_json.py` を実行

### 難易度の目安

- **easy（初級）**: 夏目漱石、芥川龍之介、太宰治、宮沢賢治など有名作家の代表作
- **medium（中級）**: 森鴎外、樋口一葉、谷崎潤一郎など
- **hard（上級）**: 梶井基次郎、中島敦、坂口安吾などのやや知名度が低い作品

## 🎨 デザインのカスタマイズ

`style.css`の`:root`セクションでカラーパレットを変更できます：

```css
:root {
    --primary-green: #6b9e78;    /* メインカラー */
    --light-green: #b8d4be;      /* サブカラー */
    --sky-blue: #a8d8ea;         /* アクセントカラー */
    /* ... */
}
```

## ⚙️ 設定のカスタマイズ

`quiz.js`の冒頭の`CONFIG`オブジェクトで調整可能：

```javascript
const CONFIG = {
    TOTAL_QUESTIONS: 10,         // 出題数（デフォルト：10問）
    EXCERPT_INCREMENT: 100,      // Moreボタン1回で表示する文字数
    INITIAL_EXCERPT_LENGTH: 100, // 最初に表示する文字数
    HINT_AFTER_MORE_COUNT: 3     // 何回Moreを押したらヒント表示か
};
```

## 🔧 トラブルシューティング

### 「問題データが読み込まれていません」と表示される

- `questions-data.js` が存在するか確認
- `python3 excel_to_json.py` を実行してJSONファイルを生成

### 選択肢が重複する

- 同じ難易度の問題を最低4問以上追加してください

### Excelファイルが開けない

- openpyxlライブラリをインストール: `pip3 install openpyxl pandas`
